# Results

> **Inference option.** Everything in this folder is the published **`active`** configuration: the hybrid model as trained, selected and tested. Each sub-folder carries a `RUN_MODE.json`. The same evaluations with φ<sub>u</sub> neutralized are in [`../results_phi_neutralized/`](../results_phi_neutralized/) (post hoc). Figures of these results: [figure gallery](../figures/).

The three kinds of results are kept in separate folders and are never mixed (`docs/EVALUATION_PROTOCOL.md`).

- **How they were produced.** Every file here was regenerated by the release scripts from the processed data and the frozen models.
- **How they were checked.** Each was compared byte for byte with the corresponding output of the original project (`ORIGINAL_OUTPUTS_SHA256.txt`).
- **Identifiers.** Column and row identifiers are those of the study: `E_DIV` = DeepDAS Ensemble v1, `CR_P99` = supervised single model, `Z` = SimStudio Z-score (`docs/IDENTIFIERS.md`). The files marked *display* use the release names.

## `development/`: development data, not independent
| File | Content |
|---|---|
| `development_reproduction.csv` | the 9 development cases: windows, stored and reproduced ensemble score, decisions per vehicle unit and per track unit, single-model logit and decisions |
| `development_cases.csv` (*display*) | the same, with case ids DC-01…DC-09 and release names; DeepDAS Ensemble v1 detects 8 of 9 |

## `validation/`: used for model selection, not independent
| File | Content |
|---|---|
| `seed_<k>/vehicle_scores.csv` | per seed: logit, decision at the seed's P99/P95, group, label, windows for every validation, val_B, test-split normal, stallval, new-scene and development vehicle |
| `seed_<k>/vehicle_scores_legitimate_stop_set.csv` | per seed: the same for the legitimate-stop validation set (stopval2) |
| `ensemble_scores.csv` | per-seed z and ensemble score of every vehicle above |
| `ensemble_scores_legitimate_stop_set.csv` | the same for stopval2 |
| `validation_metrics.csv` | the selection metrics of the ensemble and of each seed: per-type recall, macro9, stall modes, tailgating, false alarms, validation AP |
| `ensemble_scores_selection_round.csv` | the ensemble scores as stored when the model was selected (the reference for E2) |

## `final_test/`: the independent final test (run once, 2026-10-09)
| File | Content |
|---|---|
| `scores_dl_tracks.csv` | DeepDAS Ensemble v1 and the single model on every usable track (deployment unit) |
| `scores_dl_oracle_vehicles.csv` | the same on simulated vehicles (secondary) |
| (input) `data/processed/final_test/zscore_scores_precomputed.csv` | SimStudio Z-score per track, computed from the raw exports (identical to the original `scores_zscore_tracks.csv`) |
| `vehicle_outcomes.csv` | per simulated vehicle: label, decisions of all detectors (vehicle detected if any decided track alarms) |
| `T1_per_type.csv` … `T7_zscore_top_features_on_anomalies.csv` | the pre-registered tables: per type, overall, stops and tailgating, secondary, uncertainty (bootstrap, McNemar), focus runs, Z-score features |
| `T5_uncertainty.json` | bootstrap CIs and McNemar tests |
| `FINAL_TEST_REPORT.md` (*display*) | the tables with release names |
| `records/` | the frozen plan, the readiness audit, the freeze manifests and the results report written at the time (verbatim) |
